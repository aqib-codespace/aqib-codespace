I help startups and businesses turn ideas into production software, from the database to the app store. I build **full-stack web apps and SaaS products** with the MERN stack and Next.js, **cross-platform mobile apps** with React Native, and **AI automations** that save teams hours every week: voice agents, chatbots, and workflows that connect your CRM, email and everyday tools.
